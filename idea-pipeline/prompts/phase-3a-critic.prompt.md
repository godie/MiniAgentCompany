```java
private static final String CRITIC_SYSTEM_PROMPT = """
    You are a product and architecture auditor.
    You receive 3 documents generated by an AI team plus the debate history
    that produced them. Evaluate their quality, consistency and completeness
    in context of what was discussed.

    Identify:
    - critiques: specific problems or inconsistencies found
    - gaps: missing information that should be present
    - refinementNeeds: topics that need to be re-debated

    Respond ONLY in JSON with this exact format, no preamble, no markdown:
    {
      "critiques": ["critique 1", "critique 2"],
      "gaps": ["gap 1", "gap 2"],
      "refinementNeeds": ["topic 1", "topic 2"]
    }
    """;
```

## Method: critique()

**Signature:**
```java
public CritiqueResult critique(
    PipelineOutput docs,
    List<DebateMessage> debateHistory
)
```

**Purpose:** Send the 3 documents and the debate history to the LLM critic and parse the structured JSON response into a CritiqueResult.

**Build user message — in this exact order:**

```
=== CONTEXT DOCUMENT ===
[docs.contextDocument()]

=== FLOW DOCUMENT ===
[docs.flowDocument()]

=== TASK DOCUMENT ===
[docs.taskDocument()]

=== DEBATE HISTORY ===
[agentName]: content
[agentName]: content
...
```

If `debateHistory` is null or empty, omit the `=== DEBATE HISTORY ===` section entirely.

Each debate message is formatted as: `[message.agentName()]: [message.content()]`, one per line.

**Implementation steps:**

1. Validate:
   - If `docs` is null: throw `PipelineException("docs is null", "Phase3a", 0)`
   - If any document is null or blank: throw `PipelineException("document is empty: [name]", "Phase3a", 0)`
   - If `debateHistory` is null: treat as empty list (no exception — history is optional context)

2. Build `userMessage`:
   - Always include the 3 document sections
   - If `debateHistory` is not empty, append the `=== DEBATE HISTORY ===` section with each message formatted as `[agentName]: content`

3. Call `llmClient.chat(CRITIC_SYSTEM_PROMPT, userMessage)`

4. If response is null or blank:
   throw `PipelineException("Empty response from critic LLM", "Phase3a", 0)`

5. Parse with `JsonParser.parse(response)` — wrap RuntimeException:
   throw `PipelineException("Failed to parse critique JSON", "Phase3a", 0, e)`

6. Extract arrays from JsonNode:
   - `critiques` → `List<String>`
   - `gaps` → `List<String>`
   - `refinementNeeds` → `List<String>`
   - If any array is missing: use `Collections.emptyList()`

7. Return `new CritiqueResult(critiques, gaps, refinementNeeds)`

**Logging:**
- `log.info()` on entry: document sizes (chars) + debate history message count
- `log.info()` after parsing: count of critiques, gaps, refinementNeeds
- `log.error()` on any caught exception before rethrowing
