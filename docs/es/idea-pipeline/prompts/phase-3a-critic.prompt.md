## System prompt — definir como constante private static final String

```java
private static final String CRITIC_SYSTEM_PROMPT = """
    You are a product and architecture auditor.
    You receive 3 documents generated by an AI team plus the debate history
    that produced them. Evaluate their quality, consistency and completeness
    in context of what was discussed.

    Identify:
    - critiques: specific problems or inconsistencies found
    - gaps: missing information that should be present
    - refinementNeeds: topics that need to be re-debated

    Respond ONLY in JSON with this exact format, no preamble, no markdown:
    {
      "critiques": ["critique 1", "critique 2"],
      "gaps": ["gap 1", "gap 2"],
      "refinementNeeds": ["topic 1", "topic 2"]
    }
    """;
```

## Método: critique()

**Firma:**
```java
public CritiqueResult critique(
    PipelineOutput docs,
    List<DebateMessage> debateHistory
)
```

**Propósito:** Enviar los 3 documentos y el historial de debate al LLM crítico y parsear la respuesta JSON estructurada en un CritiqueResult.

**Construir el mensaje de usuario — en este orden exacto:**

```
=== CONTEXT DOCUMENT ===
[docs.contextDocument()]

=== FLOW DOCUMENT ===
[docs.flowDocument()]

=== TASK DOCUMENT ===
[docs.taskDocument()]

=== DEBATE HISTORY ===
[agentName]: content
[agentName]: content
...
```

Si `debateHistory` es null o está vacío, omite la sección `=== DEBATE HISTORY ===` por completo.

Cada mensaje de debate se formatea como: `[message.agentName()]: [message.content()]`, uno por línea.

**Pasos de implementación:**

1. Validar:
   - Si `docs` es null: lanzar `PipelineException("docs is null", "Phase3a", 0)`
   - Si algún documento es null o está en blanco: lanzar `PipelineException("document is empty: [name]", "Phase3a", 0)`
   - Si `debateHistory` es null: tratarlo como lista vacía (sin excepción — el historial es contexto opcional)

2. Construir `userMessage`:
   - Incluir siempre las 3 secciones de documentos
   - Si `debateHistory` no está vacío, añadir la sección `=== DEBATE HISTORY ===` con cada mensaje formateado como `[agentName]: content`

3. Llamar a `llmClient.chat(CRITIC_SYSTEM_PROMPT, userMessage)`

4. Si la respuesta es null o está en blanco:
   lanzar `PipelineException("Empty response from critic LLM", "Phase3a", 0)`

5. Parsear con `JsonParser.parse(response)` — envolver RuntimeException:
   lanzar `PipelineException("Failed to parse critique JSON", "Phase3a", 0, e)`

6. Extraer arrays del JsonNode:
   - `critiques` → `List<String>`
   - `gaps` → `List<String>`
   - `refinementNeeds` → `List<String>`
   - Si falta algún array: usar `Collections.emptyList()`

7. Devolver `new CritiqueResult(critiques, gaps, refinementNeeds)`

**Logging:**
- `log.info()` al entrar: tamaños de los documentos (caracteres) + número de mensajes del historial de debate
- `log.info()` tras el parseo: recuento de critiques, gaps, refinementNeeds
- `log.error()` en cualquier excepción capturada antes de relanzarla
